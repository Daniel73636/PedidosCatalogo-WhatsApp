# Privacidad y tratamiento de datos — Ley 1581 de 2012

El comercio actúa como responsable del tratamiento. Al confirmar un pedido, el cliente autoriza usar nombre, teléfono, dirección y datos del pedido exclusivamente para preparación, entrega, soporte y comunicaciones operativas. El consentimiento es previo, explícito y versionado; no habilita publicidad.

El titular puede solicitar consulta, corrección, exportación, revocación o supresión. La API administrativa ofrece exportación y anonimización, pero producción debe verificar la identidad del solicitante, conservar evidencia de la solicitud y aplicar los plazos y excepciones legales. Deben definirse responsable, canal de contacto, política de retención, tratamiento de backups y contratos con encargados (hosting, WhatsApp y pagos) antes del lanzamiento.
